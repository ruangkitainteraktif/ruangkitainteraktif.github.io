Fitur Utama
🗺️
GEOID — Batas Wilayah
Pencarian batas wilayah administrasi Provinsi, Kabupaten/Kota, Kecamatan, hingga Desa/Kelurahan. Klik di peta untuk melihat data lengkap wilayah.
🌾
GEOTANI — Analisis Pertanian
Analisis Lahan Baku Sawah (LBS), overlay erosi (KTA), indeks vegetasi NDVI, dan Land Cover berbasis Sentinel-2. Lengkapi dengan pencarian BPP & IGT Sawit.
📡
GEOPORTAL
Layer data Pemprov Jawa Timur & Kabupaten Sukoharjo (pendidikan, kesehatan, transportasi, aset daerah).
🎥
GEOWATCH — CCTV
Monitoring CCTV lalu lintas jalan tol, nasional, dan non-tol dengan video streaming real-time.
🌤️
GEOWX — Cuaca BMKG
Prakiraan cuaca BMKG + animasi angin (wind particle) untuk setiap wilayah di Indonesia.
🔴
GEOQUAKE — Gempa Bumi
Data gempa bumi real-time dari BMKG dengan magnitude, kedalaman, dan lokasi.
🛠️
TOOLS — Alat Analisis
Gambar (titik, garis, poligon), ukur jarak & luas, import GeoJSON/SHP, export PDF.
Teknologi yang Digunakan
Leaflet.js Turf.js ArcGIS BMKG API Sentinel-2 Esri Leaflet jsPDF Video.js HLS.js proj4js jQuery jsTree shpjs MarkerCluster
